# Cooperative Answering

[English](README.md) | 简体中文

一个基于保罗·格赖斯合作原则的智能体 skill，用于清晰、面向读者的沟通，以及遇到异常立即暴露问题的软件工程实践。

本 skill 涵盖写作、生产代码、错误处理和测试：

- **沟通：** 通过具体机制解释行为，将写作指令与交付内容分离，使用简洁、肯定式的表达，并提供中英文示例。
- **错误处理：** 立即向上传播意外异常。在外部 I/O 边界捕获特定异常时，应执行需求明确规定的恢复策略，或补充上下文后重新抛出。
- **测试：** 使用最少的测试准备数据和对象，验证真实对象、状态和执行路径，重点发现生产行为的回归问题。

## 安装

将本仓库克隆到智能体的 skill 目录中，并以 skill 名称作为文件夹名：

```sh
git clone https://github.com/Kuro96/cooperative-answering.git <skills-directory>/cooperative-answering
```

将 `<skills-directory>` 替换为你的智能体支持的 skill 存放路径。skill 定义见 [`SKILL.md`](SKILL.md)。

## 使用

在构建、测试或解释软件之前，请智能体加载 `cooperative-answering`。适用任务包括撰写回复、文档、提交信息和代码注释，以及修改生产代码、错误处理、测试及其准备数据和对象。skill 的描述要求在这些任务中自动启用；实际启用方式取决于宿主智能体的 skill 加载机制。
